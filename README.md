OIBSIP-Python-Task1-VoiceAssistant# Voice Assistant



\## Objective

To build a Python-based voice assistant that listens to spoken commands and responds with useful actions.



\## Technologies Used

\- Python

\- SpeechRecognition

\- Pyttsx3

\- Datetime

\- Webbrowser



\## Features

\- Voice input through microphone

\- Greeting response

\- Tells current date and time

\- Performs web searches

\- Text-to-speech responses

\- Handles errors when speech is not understood



\## How to Run



1\. Install Python.

2\. Install the required libraries.

3\. Run the Python file.

4\. Speak a command through the microphone.



\## Project File

\- `voice\_assistant.py`
